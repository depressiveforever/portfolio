## About

Personal portfolio and resume site, built as a static single-page-per-language site (English / Russian) with no build step or dependencies — plain HTML, CSS and JS, deployed via GitHub Pages.

## Stack

- Python, Java, Lua, C#, C++
- JavaScript, TypeScript, Node.js
- HTML5, CSS3
- SQL / MySQL / PostgreSQL / SQLite

## Structure

| File | Purpose |
|---|---|
| `index.html` | Root redirect — sends visitors to `en.html` or `ru.html` based on browser language |
| `en.html` | English version of the site |
| `ru.html` | Russian version of the site |
| `404.html` | Custom 404 page |
| `LICENSE` | Repository license |
